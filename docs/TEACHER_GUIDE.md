# Teacher Guide

1. Register or log in through **Teacher Login**.
2. Create a Classroom and share its Classroom ID.
3. Upload a PDF/DOCX RPP, run AI Analysis, confirm the learning level, and generate content.
4. Use Self Learning previews and the Live Quiz Wizard for Reading, Listening, Speaking, Writing, Mixed Skills, or Final Challenge.
5. Open Analytics to inspect real activity metrics, Student identities, competencies, difficult questions, and recommendations.
6. Review Speaking/Writing submissions before applying a reasoned score override.
7. Export CSV or print reports.
8. Use Settings to control joining, approval, review visibility, replay limits, Classroom ID, and archive status.

Teacher recommendations assist professional judgment and never rewrite original scores automatically.
