# EnglAI 1.0.0

EnglAI 1.0.0 is the first full release of the AI Classroom Platform. It provides RPP-scoped content, permanent and guest identities, Self Learning for four skills, multi-skill Live Quiz, analytics, Teacher review, reporting, classroom configuration, and demo-safe AI fallback.

Production deployments must configure HTTPS, a unique `APP_KEY`, restricted MySQL credentials, private backups, and a valid Gemini key when AI-provider output is required.
